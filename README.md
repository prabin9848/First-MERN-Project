# 📝 Full-Stack MERN Notes Application

A full-stack note-taking web application built on the **MERN** stack (MongoDB, Express.js, React 19, Node.js) with **Vite** and **Upstash Redis**. It provides real-time CRUD operations for personal notes, secure database persistence, and API rate-limiting to prevent spam and abuse.

---

## ✨ Features

### 🎨 Frontend
- **Modern React 19 & Vite Pipeline:** Lightning-fast HMR during development and optimized single-page bundle builds (`dist`) for production.
- **Dynamic Note Interface:** Responsive layout for viewing, adding, editing, and deleting notes seamlessly.
- **Unified Full-Stack Deployment:** Integrated directly with the Express backend to serve production assets effortlessly.

### 🛡️ Backend & API
- **Full CRUD Endpoints:** RESTful API routes handling complete note management lifecycle.
- **Database Persistence:** MongoDB Atlas integration using Mongoose models with dynamic `createdAt` and `updatedAt` timestamps.
- **Sliding-Window Rate Limiting:** API security powered by **Upstash Redis** (`@upstash/ratelimit`) limiting requests to 100 per minute per client.
- **Network Resilience:** Custom DNS fallback configuration for reliable database connections across varied network environments.
